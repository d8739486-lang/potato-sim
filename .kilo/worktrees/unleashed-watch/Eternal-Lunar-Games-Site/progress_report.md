Интеграция HTML для API Ключей

Внедрить твой HTML/CSS шаблон генератора ключей.
Заложить архитектуру под особенный формат ключей. Когда ты (или следующий ИИ) вернешься к этой задаче, можно будет выбрать один из следующих вариантов генерации:
Классический с префиксом: et-ke-aB3dE5fG... (легко узнать, какому проекту принадлежит ключ).
С разделением (UUID-подобный): ETL-A1B2-C3D4-E5F6 (удобно диктовать или копировать частями).
Скрытый хэш (JWT-style): et.eyJhbG... (позволяет зашифровать внутрь ключа срок его действия без обращения к БД).
Игровой формат (Steam-style): ETLNR-ABCDE-12345 (отлично вписывается в тематику игрового сайта).
Добавить возможность выбирать срок действия (срок годности) сгенерированного ключа.
Привязать эти ключи к базе данных Supabase для валидации.
