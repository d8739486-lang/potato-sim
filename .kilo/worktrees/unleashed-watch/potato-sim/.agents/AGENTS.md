# User Rules

- Всегда делай деплой на Vercel (npm run vercel, vercel --prod, или аналогичную команду) после завершения любой значимой задачи или добавления фичи.
- Никогда не использовать субагентов в браузере (browser_subagent) в этом проекте.
- Не запускать локальный сервер (localhost / npm run dev / vite) — пользователь запускает dev-сервер самостоятельно.
