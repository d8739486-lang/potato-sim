# PC MASTER 3 - Project Overview

**Concept:** Psychological cyber-horror simulator.
**Genre:** Operating System Simulation / Thriller.
**Current Version:** 0.0.1-prototype
**Status:** In Development (Stage: Initialization & Main Menu)

## Plot Summary
PC MASTER 3 explores the destruction of trust. The player attempts to return to a normal life, but the system begins acting as a living organism. The best friend may be an antagonist or a pawn of Digital Dreams (DD).

## Core Systems
1. **Initialization Sequence:** Start Screen -> Preloader (with sync) -> Language Selection -> Main Menu.
2. **Desktop Interface:** Windows-like shell with Taskbar and Icons. (Planned)
3. **WhatisUp:** Dialogue system. (Planned)
4. **System Logs:** Live logging mechanism with interactive update history.
5. **Corruption System (DD):** Digital Dreams interference engine. (Planned)

## Tech Stack
- TypeScript, Vite, Web APIs.
- Assets: `/assets/images`, `/assets/sounds/sfx`, `/assets/sounds/soundtracks`.
