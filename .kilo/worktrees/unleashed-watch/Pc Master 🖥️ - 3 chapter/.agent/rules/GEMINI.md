# Project: [project-name]

## General Instructions

- When you generate new TypeScript code, follow the existing coding style.
- Ensure all new functions and classes have JSDoc comments.
- Prefer functional programming paradigms where appropriate.

## Coding Style

- Use 2 spaces for indentation.
- Prefix interface names with `I` (for example, `IUserService`).
- Always use strict equality (`===` and `!==`).

## Natural Language & Anti-AI Tone Guardrails

- **No AI / Generic Sci-Fi Jargon:** Never use cliché AI-sounding phrases (e.g., `INTEGRITY VERIFIED`, `SYNCHRONIZING CORE DATA`, `PROTOCOL INITIALIZED`, `REBOOTING NEURAL NODE`, `SYSTEM OVERRIDE`).
- **Grounded & Human UI Copy:** Use realistic, authentic OS terms and simple natural wording:
  - Instead of `SYNCHRONIZING CORE DATA...` → `ЗАГРУЗКА РЕСУРСОВ...` / `LOADING ASSETS...`
  - Instead of `INTEGRITY VERIFIED` → `ГОТОВО` / `READY`
  - Narrative and system text must sound like real human communication, realistic Windows/BIOS interfaces, or eerie analog horror, without synthetic AI tech-babble.

## Narrative & Typography Rules

- **No Em-Dashes (— / –):** Do NOT use em-dashes or en-dashes in character dialogues, thoughts, subtitles, UI copy, or quest text. Use clean punctuation (periods, commas, simple colons).
- **Friend Name Secrecy:** Never name or reveal the friend's real identity (e.g. do not use placeholder names like "Макс"). His identity is a core late-game plot reveal.
- **Natural Subtitles & UI Copy:** Keep internal monologue and dialogue grounded, realistic, and human without cliché literary tropes.

## Design & UI Preservation Rules

- **Zero Emojis Policy:** Do NOT add emojis (e.g. 💬, 🎬, 🚀, 🔧, 📦, 🌟) into subtitles, character thoughts, dialogues, notifications, button labels, UI copy, or code. Use authentic OS icons (Bootstrap/Lucide icons) or clean text only.
- **Design Preservation:** Never change, alter, or restyle existing UI components, color palettes, or layout designs that are already built and functioning unless explicitly asked by the user. Keep existing visual elements stable across sessions and cutscenes.
