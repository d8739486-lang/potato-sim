# User Rules

- ОБЯЗАТЕЛЬНО делай деплой на Vercel в самом конце любой задачи или фичи: фиксируй изменения и делай `git push origin main` (так как Vercel автоматически деплоит из репозитория при пуше в main), либо используй `vercel --prod` при наличии токена/авторизации. В ответе всегда приводи ссылку https://potato-sim.vercel.app/ . Никогда не завершай ответ без деплоя/пуша.
- Никогда не использовать субагентов в браузере (browser_subagent) в этом проекте.
- Не запускать локальный сервер (localhost / npm run dev / vite) — пользователь запускает dev-сервер самостоятельно.
- Всегда использовать скиллы, когда они нужны.
- В КАЖДОМ сообщении обязательно писать, какие скиллы активны (если активных нет — писать "Скиллы: 0" или "Скиллы: не задействованы").
- Каждые 25 сообщений писать, сколько процентов занято из всего контекста.
- ПЕРЕД разработкой игровых механик, систем прогрессии, перерождений или эволюций ОБЯЗАТЕЛЬНО искать реальные игровые схемы и референсы в интернете (например, Roblox "Sell Lemons" и др.), а не выдумывать наугад.
